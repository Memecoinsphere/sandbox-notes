Sandbox Notes — guide d'utilisation (français)
===============================================

Installation sur iPhone
-----------------------
1. Ouvrez le site dans Safari.
2. Appuyez sur le bouton Partager (carré avec flèche vers le haut).
3. Choisissez « Sur l'écran d'accueil », puis Ajouter.
4. Lancez « Sandbox Notes » depuis l'écran d'accueil (mode autonome).

Sur Android (Chrome) : menu ⋮ → « Installer l'application » ou
« Ajouter à l'écran d'accueil ».

Déverrouillage (geste caché)
----------------------------
Au lancement, l'écran affiche une surface neutre (horloge sobre).
Ce n'est PAS l'écran de code.

Pour révéler l'écran de code :
  → Double-tapez rapidement près du HAUT de l'écran
    (bandeau supérieur, environ les 15 % du haut).

Puis saisissez le code : 6767
Un code erroné affiche « Incorrect passcode » et l'app reste verrouillée.

Code d'accès
------------
Code actuel : 6767

Pour le changer, éditez dans app.js la constante clairement marquée :
  // ===== PASSCODE (change here) =====
  const PASSCODE = "6767";

Verrouillage
------------
Dans l'app, le bouton rouge « Lock » renvoie à la surface leurre
(horloge). Le geste caché est à nouveau nécessaire.

Fonctionnement
--------------
Section « App notes » : la liste de vos notes (vide au départ). Chaque
ligne affiche le nom de l'app (titre), le risque (low/medium/high, en
orange) et le texte libre éventuel. Un bouton « Delete » supprime la
ligne.
Section « Add » : champ « App name », sélecteur Risk (low/medium/high,
défaut medium) et bouton « Add » qui ajoute la note.
Tout est mémorisé localement sous la clé localStorage « sandbox_apps ».

LIMITES IMPORTANTES (à lire)
----------------------------
Cette app est un simple registre LOCAL : rien n'est analysé, détecté ou
vérifié automatiquement. Les notes et niveaux de risque sont saisis par
vous et stockés uniquement dans ce navigateur (clé « sandbox_apps »).

Tout est LOCAL : les données sont mémorisées uniquement dans le
navigateur (localStorage) de cet appareil. Aucun appel réseau, aucune
analytique. Effacer les données du site efface tout. Ce guide n'est pas
lié depuis l'application.

Fichiers
--------
Tout est statique (HTML/CSS/JS), sans étape de build ni CDN externe.
